## Evidence and independence

Preserve existing HTTP402 containment, received-output validation and diagnostic regressions. Every later result records exact source SHA, design hash, executable/Node/Yarn/Electron/provider/backend/crypto versions, exact command, fixture identity, fault schedule, observed pass/fail/skip counts and limitations. Untouched-source failures are PRE-REMEDIATION BASELINE FAILURE. Synthetic reviewer checks are historical evidence only; no result is transferred into this matrix.

Mock tests, real backend callback/reopen tests, controlled process termination, packaged Windows integration, storage-crash/power-failure testing, offline restoration and independent post-fix verification require separate evidence. Clean read-back/reopen does not prove power-loss survival. RC03-01/RC03-SEC-01 and RC03-09 need fresh independent exact-SHA verification; no closure by this plan. R7-02 now accepts valid padded 32-byte scalar1, rejects invalid range/width, and pins key encoding.

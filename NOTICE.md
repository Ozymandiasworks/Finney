# Finney provenance notice

Finney is a derivative of the open-source Stamp client (`StampChat/stamp`).

The original Stamp README states that the GUI is licensed under GPLv3 and that
`src/cashweb/` is MIT-licensed. Finney preserves the repository's original
`LICENSE` file and source history in the development branch.

Working name: Finney
Milestone: 0.1.0-alpha.1

Alpha.20 is a stabilization build. It preserves the proven alpha.19 stamp cryptography/constructor and canonical XEC txid implementation under automated hash locks. Development proof controls are not intended as production user features.
